Statement: Investigating how different generative models such as GPT, Claude, and Gemini are using memorization or true reasoning to solve logic problems and the effect of various prompt forms on the accuracy of the answer.
Proposed Approach: Model evaluation study. I will employ zero-shot and chain-of-thought prompts with different state-of-the-art models and analyze the results in terms of accuracy and logic. 
Data Sources: A set of carefully chosen publicly available logic problems and word math problems (Kaggle or Hugging Face).
